## ✨ Features

- 📸 **Instagram Downloader:** Download Reels, Posts, and Stories in high resolution.
- 🎥 **YouTube Downloader:** Download high-quality YouTube videos and shorts.
- 🎬 **Desktop VLC Parser:** Bypass unconfigured protocol handlers on Mac/Windows by generating `.m3u` files directly from Intent URLs.
- 🎵 **JioSaavn & Spotify (Coming Soon):** High-quality audio extraction for popular music platforms.
- 📱 **Responsive Design:** Beautiful, glassmorphic UI built with Tailwind CSS that works seamlessly across desktop and mobile.

## 🛠️ Built With

- **HTML5 & CSS3**
- **JavaScript (Vanilla)**
- **Tailwind CSS** (via CDN for rapid UI development)
- **Firebase Hosting**

## 🚀 Getting Started

If you want to run this project locally, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ashish8381/downloader.git
   ```

2. **Open the project:**
   Navigate into the directory and open `index.html` in your favorite browser.
   ```bash
   cd downloader
   open index.html # On macOS
   # OR double-click the file in your file explorer
   ```
